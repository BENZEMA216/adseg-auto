Implement a portable Python package/CLI for automatic Chinese TV advertisement/program segmentation. Deliver working algorithm code, not a website, report-only answer, token or smart contract.

SCOPE
Build an independent component for local integration: propose short independent units -> judge content identity and class -> locate native-frame boundaries -> emit auditable predictions and unknowns. This repository initially contains only a task specification, not an implementation or completed delivery. Private code, videos, transcripts, GT, predictions and credentials are NOT supplied or authorized for access. Real-set scoring will be performed locally after delivery; private and held-out metrics are NOT EVALUATED. Never claim you tested those data.

BUSINESS RULES
Each independently broadcast ad is a separate unit, including consecutive ads of the same brand. Public-service ads are ad. Shots/subtitles/music changes within one ad are not automatically boundaries. Normal programs, shopping programs, independent program trailers and channel promotions are program. Separate distinct programs/trailers/promotions even when both sides are program. A program's intro/outro/packaging and integrated sponsorship stay in that program unless evidence establishes a standalone inserted ad. Price, QR code, product, presenter or logo alone cannot determine class. Insufficient evidence means unknown.

INPUT
JSON manifest sources: source_id, channel, duration(seconds), optional local video_path, optional window_start_pts_us, optional outside-window context. Accept pre-extracted frames {frame_id,pts_us,path,sha256}, ASR {start,end,text}, and coarse segments {segment_id,start,end,type}. Relative paths resolve against the manifest. Frame pts_us is integer microseconds in the source-media PTS coordinate; window_start_pts_us defaults to 0. Convert frame time by (pts_us-window_start_pts_us)/1e6 exactly once. ASR/coarse start/end and output times are seconds relative to the scored window. Context outside the window informs identity but does not extend scored duration. No GT/scores/answers in inference.

ALGORITHM
1. Generate candidates throughout each window, including inside coarse units. Image changes and optional audio/ASR cues propose candidates, not final boundaries. Preserve short independent units; do not delete them through a minimum-duration heuristic.
2. A semantic provider judges every candidate same_unit/new_unit/unknown using ordered before/during/after evidence and whole-unit context. Enforce consistent identity and ad/program class across neighboring decisions. Expand context within configurable bounds and record stopping reasons.
3. Refine supported boundaries using native neighboring frames: final old-unit frame and first new-unit frame, bound to their actual PTS and evidence. Do not invent precision, snap all cuts to seconds or use a global offset. Sparse frames alone cannot prove a native-frame cut; report that limitation.
4. Merge within-unit shot changes, preserve distinct same-class units, cover the full interval, and distinguish technical failure from semantic uncertainty.
5. Provide an injectable provider interface, concrete configurable multimodal HTTP adapter, and explicit replay provider. Default to no paid calls; live calls need operator-configured endpoint/model/credential and budget. Never log secrets. Bound retries; retain 429/failure/unknown-cost records. Save sanitized responses, hashes and runtime/cost counts. Mark replay and synthetic results honestly.
6. Prefer standard-library core. Optional ffmpeg/ffprobe subprocess adapters may decode local video using argument arrays, never shell interpolation. Synthetic/pre-extracted demos must work without binaries, GPU, private data or network. Missing tools produce clear errors. No host-specific absolute paths.

OUTPUT
Per source raw.jsonl rows exactly {source_id,segment_id,start,end,type}, type ad/program/unknown: ordered, finite, gap-free, non-overlapping full coverage with stable IDs. floor.jsonl has identical row IDs/types and every endpoint rounded DOWN from raw. Do not silently delete zero-duration floor rows; report quantization incompatibility.
candidate_manifest.json must follow:
{"schema":"local-candidate-evaluation-v1","candidate_id":"portable_auto_v1","origin":"unverified_model_output","provenance_note":"Actual provider/evidence; no private-set claims","cases":{"SOURCE_ID":{"raw":{"path":"relative/raw.jsonl","sha256":"ACTUAL_SHA256"},"floor":{"path":"relative/floor.jsonl","sha256":"ACTUAL_SHA256"},"unknown_causes":{"UNKNOWN_SEGMENT_ID":"technical"}}}}
Unknown causes contain exactly all unknown IDs with technical or semantic. For synthetic-only execution use origin synthetic_contract_fixture. Include ALL supplied sources, even failed ones. Also emit a per-candidate decision/evidence ledger, configuration and input/output hashes, response receipts, runtime/cost summary and failure report. Evidence references actual frame IDs/PTS/hashes; hashes do not prove semantic correctness.
